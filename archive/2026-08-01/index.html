get the ball rolling
/ɡɛt ðə bɔːl ˈroʊlɪŋ/
أن نبدأ بشيء
📖 الشرح
يعني أن نبدأ شيئًا، مثل مشروع أو نشاط. تستخدم هذه العبارة عندما تريد تحفيز الآخرين للبدء في العمل.
💬 أمثلة على الاستخدام
Let's get the ball rolling on this project so we can finish it on time.
We need to get the ball rolling if we want to meet our deadlines.
It's time to get the ball rolling and start the meeting.
إعلان
